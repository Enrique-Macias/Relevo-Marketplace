# 1. Identidad del servicio

Nombre comercial: RLVO

Dominio:
https://rlvo.com.mx

Mercado:
México.

Lanzamiento inicial:
Universidades seleccionadas de Nuevo León, México.

Fecha objetivo de lanzamiento:
Octubre de 2026.

RLVO es un marketplace móvil dirigido inicialmente a estudiantes universitarios.

La aplicación permite descubrir publicaciones, publicar productos y contactar a otros usuarios.

RLVO no procesa pagos en su MVP.

RLVO no proporciona logística ni organiza entregas.

Comprador y vendedor coordinan directamente:

- precio;
- método de pago;
- lugar de encuentro;
- entrega;
- demás condiciones de la operación.

RLVO no cobra comisión por las compraventas en el MVP.

RLVO no es parte de la compraventa realizada entre usuarios.

# 3. Edad mínima

RLVO es exclusivamente para personas de 18 años o más.

No se permiten menores de edad.

Durante el registro se mostrará una confirmación equivalente a:

"Tengo 18 años o más."

Los Términos deberán establecer esta restricción.

Si RLVO detecta una cuenta perteneciente a un menor de edad, podrá suspenderla.

---

# 4. Acceso mediante correo universitario

El registro requiere un correo institucional perteneciente a un dominio admitido por RLVO.

Dominios inicialmente admitidos:

- tec.mx
- tecmilenio.mx
- u-erre.mx
- uanl.edu.mx
- udem.edu

El dominio:

exatec.tec.mx

no deberá aceptarse.

La validación deberá realizarse también en servidor.

La universidad correspondiente se determina a partir del dominio institucional.

El usuario no puede cambiar manualmente su universidad.

La verificación consiste en demostrar acceso al correo institucional mediante un código de seis dígitos enviado por Supabase Auth.

La cuenta puede permanecer activa mientras el correo institucional siga activo.

RLVO se reserva la posibilidad de solicitar reverificación o suspender el acceso si existen motivos para considerar que el usuario ya no pertenece a una comunidad admitida.

---

# 5. Significado de la verificación

La insignia de verificación de RLVO significa exclusivamente que el usuario demostró acceso a un correo institucional perteneciente a un dominio aceptado por RLVO.

No significa:

- que RLVO haya verificado legalmente su identidad;
- que RLVO garantice que la persona sea actualmente estudiante;
- que RLVO garantice su conducta;
- que RLVO garantice una transacción;
- que la universidad respalde al usuario.

No utilizar expresiones como:

"usuario real verificado"

"estudiante real verificado"

si pueden interpretarse como verificación de identidad.

- contraseña gestionada por Supabase Auth;
- ID interno;
- fecha de registro;
- último inicio de sesión;

Datos opcionales:

- carrera;

- apellido separado;

# 9. Teléfono y WhatsApp

El teléfono es obligatorio únicamente para usuarios que quieran publicar.

No es obligatorio para navegar.

Se permiten números internacionales porque pueden existir estudiantes foráneos con correo institucional admitido.

El número permanece privado.

Solo se proporciona individualmente cuando un usuario activo selecciona la acción para contactar al vendedor mediante WhatsApp.

RLVO abre WhatsApp desde el dispositivo del usuario.

RLVO no envía directamente el número a Meta mediante una integración de marketplace.

Al tocar "Contactar por WhatsApp", RLVO registra internamente:

- usuario que realizó el contacto;
- publicación;
- fecha/hora del contacto.

Este registro puede utilizarse para:

- el flujo "¿A quién le vendiste?";
- funcionalidades relacionadas con la transacción;
- recomendaciones internas.

Si RLVO permite posteriormente navegación pública sin cuenta, deberá revisarse la documentación de privacidad correspondiente.

# 11. Eliminación de publicaciones

Cuando un usuario elimina una publicación:

- la publicación se elimina;
- sus fotografías se eliminan físicamente.

Excepción:

Puede conservarse un registro mínimo de moderación relacionado con publicaciones infractoras.

Ese registro:

- no conserva las fotografías;
- puede conservarse durante 12 meses;
- se utiliza para reincidencias y disputas.

Una publicación bloqueada puede conservar sus fotografías ocultas mientras la publicación continúe existiendo.

Las publicaciones vendidas permanecen en el historial del vendedor hasta que:

- el vendedor las elimine; o
- elimine su cuenta.

---

# 12. Fotografías

Las fotografías de publicaciones se almacenan en Supabase Storage.

Las fotografías de perfil también se almacenan en Supabase Storage.

Al eliminar una publicación, sus fotografías se eliminan físicamente, salvo las excepciones documentadas para contenido bloqueado mientras siga existiendo.

Al eliminar una cuenta se eliminan definitivamente las fotografías asociadas a esa cuenta.

---

# 13. Reseñas y calificaciones

Las reseñas solamente pueden existir entre comprador y vendedor después de que el vendedor registre una venta.

Las reseñas funcionan en ambos sentidos.

Una reseña incluye:

- calificación de 1 a 5 estrellas;
- comentario opcional;
- relación con una publicación concreta.

Cuando un usuario elimina su cuenta:

Reseñas recibidas:
- se eliminan.

Reseñas escritas:
- se anonimizan;
- se conservan las estrellas;
- se elimina el autor;
- se elimina el comentario.

RLVO almacena favoritos.

Cada publicación puede mantener un contador agregado de vistas.

RLVO registra de forma limitada:

- contactos iniciados;

# 17. Ubicación

RLVO solamente solicita ubicación cuando el usuario selecciona voluntariamente:

"Detectar campus más cercano"

Se utiliza ubicación aproximada.

El cálculo se realiza en el dispositivo.

La ubicación:

- no se envía a Supabase;
- no se almacena en la base de datos;
- no se guarda en almacenamiento local por RLVO.

RLVO conoce adicionalmente:

- universidad derivada del correo;
- campus elegido por el usuario.

Si en el futuro se implementan funciones como "productos cerca de mí", deberán actualizarse el Aviso de Privacidad y los permisos correspondientes.

# 18. Moderación automatizada

RLVO utiliza moderación automática antes de permitir determinadas publicaciones o imágenes.

Proveedores previstos para producción:

- Google Cloud Vision;
- Amazon Rekognition;
- OpenAI.

Google Cloud Vision recibe:

- fotografías de publicaciones;
- fotografías de perfil.

También puede realizar OCR.

Amazon Rekognition recibe:

- fotografías de publicaciones.

OpenAI recibe:

- título de publicación;
- descripción de publicación.

OpenAI no recibe imágenes dentro de este flujo.

# 20. Decisiones automatizadas y revisión humana

Puede existir bloqueo automático cuando:

- existe coincidencia clara con una lista prohibida;
- existe contenido explícito claramente identificado.

Se solicita revisión humana cuando:

- el proveedor devuelve una probabilidad dudosa o elevada que requiera interpretación;
- existe detección mediante OCR que requiera revisión;
- Amazon Rekognition produce una detección que requiera revisión.

Para fotografías de perfil, el avatar solo deberá eliminarse automáticamente ante contenido considerado altamente probable conforme a las reglas internas.

Los tres fundadores podrán realizar revisiones desde el panel administrativo cuando esté disponible.

Durante desarrollo, el desarrollador puede realizar revisión mediante Supabase Studio.

---

# 21. Registro de moderación

Por cada evaluación puede conservarse:

- proveedor;
- categorías;
- confianza;
- veredicto;
- decisión final.

Para infracciones puede conservarse un registro mínimo sin fotografías durante 12 meses para:

- detectar reincidencias;
- resolver disputas;
- aplicar políticas.

# 22. Información al usuario sobre moderación por proveedores

Antes de que una imagen o texto del usuario sea enviado por primera vez a los proveedores externos de moderación, RLVO mostrará información específica sobre ese procesamiento.

Se mostrará antes de:

- primera fotografía de perfil; o
- primera publicación;

según cuál ocurra primero.

La interfaz identificará:

- OpenAI;
- Google;
- Amazon;
- qué información se envía;
- para qué se utiliza.

- fecha;

Si el usuario no acepta:

- puede seguir navegando;

- no puede subir fotografía de perfil.

Si cambian los proveedores relevantes, deberá solicitarse nuevamente la aceptación correspondiente.

# 23. Suspensiones

Una cuenta puede suspenderse por:

- publicaciones prohibidas;
- reportes repetidos;
- fraude;
- acoso;
- spam;
- infracciones similares.

Puede existir suspensión:

- temporal;
- permanente.

La suspensión temporal puede levantarse mediante reactivación manual.

La suspensión permanente puede utilizarse por reincidencia o infracciones graves.

Entre 3 y 5 reincidencias pueden llevar a suspensión permanente dependiendo de gravedad.

Casos graves pueden provocar suspensión inmediata.

---

# 24. Prevención de re-registro

Cuando una cuenta suspendida es eliminada, RLVO puede conservar un hash SHA-256 derivado del correo institucional para impedir que el mismo correo vuelva a registrarse.

Este hash solamente se conserva para cuentas que estaban suspendidas.

No se conserva el correo completo para esta finalidad.

Periodo decidido por producto:
indefinido.

# 26. Reportes

Los usuarios pueden reportar:

- publicaciones;
- usuarios.

En el MVP las reseñas no tienen flujo de reporte independiente.

Un reporte puede contener:

- motivo;
- comentario opcional;
- usuario reportante;
- publicación o usuario reportado;
- fecha;
- estado;
- snapshot del título o correo necesario para el caso.

Estados:

- pendiente;
- resuelto;
- descartado.

No existen adjuntos en el flujo inicial.

El usuario reportado no conoce la identidad de quien realizó el reporte.

Los reportes pueden conservarse durante 12 meses después de su resolución.

# 27. Eliminación de cuenta

Ruta prevista:

Perfil → engrane → Configuración → Eliminar cuenta

https://rlvo.com.mx/eliminar-cuenta

Requiere confirmación mediante contraseña.

No existe periodo de espera.

El proceso de eliminación comienza inmediatamente.

Al eliminar una cuenta desaparecen:

- perfil;
- correo;
- teléfono;
- fotografía de perfil;
- publicaciones;
- fotografías de publicaciones;
- favoritos;
- contactos;
- intereses;
- tokens de notificación;
- reseñas recibidas;
- registro de comprador;
- avisos de otros usuarios que contengan su nombre o publicaciones.
